# CS F407 Artificial Intelligence: Lab Solutions

Weekly lab solutions for CS F407 (Artificial Intelligence) at BITS Pilani, K K Birla Goa Campus. Click a week's topic to open its folder, which contains:

- **`lab-question/`**: the question PDF;
- **`solution/`**: a Jupyter notebook with the code, outputs and inline answers;
- **`answers-to-questions/`**: the answers to the lab's questions as a standalone Markdown file;
- **`README.md`**: the lab's objective, key results and what was learned.

Separates logic (applicability, effects, goal) from search, compares the LLM's self-explanation with independent execution, and uses SWI-Prolog as a separate plan verifier (optional Tasks 6–8). |
| 6 | [Building and Learning a Bayesian Network with an LLM Coding Assistant](Week6/) | [Question](Week6/lab-question/llm_bn.ipynb)<br>[Solution](Week6/solution/LLM_BN_Solution.ipynb)<br>[Answers](Week6/answers-to-questions/answers.md) | Uses Qwen2.5-Coder to generate pgmpy code for the Sprinkler network (exact inference, MLE and BDeu estimation), and executes and validates every generated program against a trusted model and an enumeration oracle. Iterates prompts and applies minimal human fixes. Compares 1.5B, 32B and Qwen3-30B models: the larger ones produce code that runs and passes check_model() but encodes the wrong distribution. Completes the query-change, CPT-explanation and sampling-variability exercises. |

Runs Mistral-7B locally with Ollama and grades it against GPT, Claude and four open models on 12 prompts, including a hallucination probe and executed code. |

Answers Q1–14 and reflects on using an LLM to write and validate the code. |

## Running the notebooks

```bash
pip install -r requirements.txt
jupyter notebook
```

Weeks 2, 3, 4 and 8 need only the Python standard library (Week 4's optional Prolog cells need SWI-Prolog). Week 1 uses PyTorch, NumPy and matplotlib (CPU only); Week 6 uses pgmpy, pandas and matplotlib; Week 7 uses NumPy, pandas, matplotlib and PyTorch (it reads saved model outputs, so no model downloads are needed).
